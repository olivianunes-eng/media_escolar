- Condicionais
- Funções
- Validação de campos
- SnackBar

### Funcionamento 

O usuário deverá informar: 
- Nome do aluno;
- Primeira nota;
- Segunda nota;
- Terceira nota;

O sistema deverá calcular a média e mostrar:
- Aprovado: média maior ou igual a 7;
- Recuperação: média maior ou igual 5 e menor que 7;
- Reprovado: média menor que 5;
